# GitHub Upload Instructions for the Current Experiment

Upload the contents of this folder to GitHub:

`outputs/github_upload_package/`

The easiest option is to upload the whole folder contents together. The main website file is `index.html`.

## What Each File Does

- `index.html`: the experiment page GitHub Pages will open automatically.
- `skeleton_code.html`: the same experiment code, kept with the clearer working name.
- `proportion_trial_list.csv`: the trial list. This controls the 25 test trials, the painter/category for each trial, the target outline, and the two response options.
- `proportion_single_category_example_list.csv`: the item-level example list. This is required. The experiment code reads this file and builds each painter/category example display from individual stimulus images.
- `proportion_design_summary.csv`: a summary of the statistical makeup for checking and explaining the design.
- `generate_experiment_from_proportions.py`: the code that generates the trial list and example list from the statistical makeup rules. Keep this so the design can be changed later.

## Required Image Folders

These folders must stay in the same structure:

- `images/gabor_frequency_options/`
- `images/trial_target_outlines/`
- `images/v6_clear_frequency_shapes/`

The CSV files point to these individual images. The experiment combines them on the page.

## Important

Do not upload or rely on files named:

- `proportion_category_example_*.png`

Those are old pre-rendered category screenshots. They are not part of the current data-driven version. In the current version, the category example display is generated by the HTML code from `proportion_single_category_example_list.csv`.
