Trial types and strategies

Every prediction trial and color memory question in pilot 2 v2, grouped by the kid's category structure. Colors are color version 1 of 5; the versions only change which real color plays each role, so the strategies are the same in every version. Under each answer option: its color code, the strategy it maps to (the saved strategy column), and the answer key's specific reason. An option with two pills fits both strategies (saved joined with "-").

Color versions

Each participant gets one of 5 color versions, chosen at the setup screen and saved as color_version. A version changes only which real color plays each color role (file number in brackets); across the versions every color plays every role once. Shapes, trials and strategies are the same in every version.
